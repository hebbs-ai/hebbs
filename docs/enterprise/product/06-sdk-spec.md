# HEBBS Enterprise: SDK Specification

## Overview

Same SDKs as the cloud version. The only difference: the `endpoint` parameter points at the customer's HEBBS server instead of `api.hebbs.ai`.

For full SDK reference (all methods, types, best practices), see [Cloud SDK Spec](../../cloud/product/06-sdk-spec.md).

---

## Python SDK

```python
from hebbs import Hebbs

# Enterprise — point at customer's server
hb = Hebbs(api_key="hb_live_sk_abc123", endpoint="https://hebbs.acme.com")

# Cloud (future) — point at our cloud
# hb = Hebbs(api_key="hb_live_sk_abc123")  # defaults to api.hebbs.ai
```

All methods:

```python
# Recall — search memories by semantic similarity
memories = hb.recall("password reset", entity_id="user_42")

# Prime — load ALL memories for an entity (context priming, no query needed)
context = hb.prime(entity_id="user_42", max_memories=30)
context.text    # pre-formatted for prompt injection

# Remember (store atomic facts)
hb.remember("Password reset is via Settings > Security", entity_id="user_42", importance=0.7)

# Revise — update an existing memory (creates revision chain, avoids contradiction)
hb.revise(memory_id="01JABCDEF...", content="User switched to light mode", importance=0.8)

# Insights (entity profiling — auto-generated by reflection)
profile = hb.insights(entity_id="user_42")

# Forget
hb.forget(entity_id="user_42")

# Index (push files)
hb.index("./docs")

# Status
info = hb.status()
```

### `prime` vs `recall` vs `insights`

| Method | What it does | When to use |
|---|---|---|
| `recall(cue)` | Semantic search — finds memories similar to the cue | "What do we know about password resets?" |
| `prime(entity_id)` | Load everything for an entity, ranked by importance | Conversation start: "load all about user_42" |
| `insights(entity_id)` | Auto-generated profile from reflection | "What patterns has the system learned about user_42?" |

Typical agent startup:
```python
# 1. Load retrieval instructions (from tuning)
rules = hb.prime(entity_id="retrieval-instructions")

# 2. Load entity profile
profile = hb.insights(entity_id=entity_id)

# 3. Recall relevant context for this specific query
memories = hb.recall(message, entity_id=entity_id)
```

## TypeScript SDK

```typescript
const hb = new Hebbs({
  apiKey: 'hb_live_sk_abc123',
  endpoint: 'https://hebbs.acme.com',
});

const result = await hb.recall({ cue: 'password reset', entityId: 'user_42' });
const context = await hb.prime({ entityId: 'user_42', maxMemories: 30 });
await hb.remember({ content: 'fact', entityId: 'user_42', importance: 0.7 });
await hb.revise({ memoryId: '01JABCDEF...', content: 'updated fact', importance: 0.8 });
const profile = await hb.insights({ entityId: 'user_42' });
```
